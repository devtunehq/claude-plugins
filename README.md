# DevTune plugins for Claude

The official DevTune plugin for Claude: see what AI answer engines tell buyers
about your product, which tools coding agents pick, what to fix next, and whether shipped fixes worked, from
your DevTune project.

## Install in Claude Code

```text
/plugin install devtune --marketplace devtunehq/claude-plugins
```

Then run `/mcp`, choose **devtune** and sign in to DevTune.

In Claude on the web, desktop or mobile, add DevTune from the connector
directory, or add `https://devtune.ai/api/mcp` as a custom connector.

See [plugins/devtune](plugins/devtune) for what the plugin covers, and the
[DevTune MCP docs](https://docs.devtune.ai/api-reference/mcp-server).
